# Quest Book a0.0.8 — Windows x64

The Russian and English editions of Quest Book are available in the same release. This is an alpha version of the standalone local quest journal for Windows 10/11 x64.

Русская и английская версии Quest Book доступны в одном релизе. Это альфа-версия самостоятельного локального журнала заданий для Windows 10/11 x64.

## Downloads / Файлы

- **EN:** `QuestBook-EN-a0.0.8-Windows-x64.zip` — run `QuestBookEN.exe`.
- **RU:** `QuestBook-a0.0.8-Windows-x64.zip` — запускайте `QuestBook.exe`.

Полностью распакуйте выбранный архив перед запуском. Не переносите EXE отдельно от остальных файлов.

Extract the complete archive before launch. Do not move the EXE away from the other included files.

## Highlights / Основные изменения

- complete Russian and English editions with separate application data;
- local automatic saving with no account or cloud synchronization;
- background rendering before the window is shown, avoiding an incomplete or black startup frame;
- instant restoration from the system tray;
- per-quest difficulty and color settings;
- configurable text sizes, interface scale, volume, and global shortcut;
- quest tree, objectives, rewards, tracking, editor, and confirmation windows.

## Local data / Локальные данные

- RU: `%APPDATA%\Quest Book\quests.json`;
- EN: `%APPDATA%\Quest Book EN\quests.json`.

The application does not send quest data to the developer and does not use telemetry or analytics.

Программа не отправляет данные заданий разработчику и не использует телеметрию или аналитику.

## Requirements / Требования

- 64-bit Windows 10 or Windows 11;
- Microsoft Edge WebView2 Runtime.

## SmartScreen

These alpha builds are not digitally signed with a paid developer certificate. Windows may display an unknown-publisher warning on first launch.

Альфа-сборки не подписаны платным сертификатом разработчика. При первом запуске Windows может показать предупреждение о неизвестном издателе.
